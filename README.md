Тестовое задание для стажера по направлению Разработчик С++

Часть 1 - pt1
файлы:
├── CMakeLists.txt - симейк лист для динамической и статической сборки бибилиотеки без второй части и юнит-тестов
├── journal.cpp - файл с реализацией методов journal.hpp
├── journal.hpp - файл с телом journal и декларацией методов
└── main.cpp - файл с проверкой работы инициализации журнала и сохранения сообщения

запуск:
```
создаём папку сборки
mkdir build
переходим в неё
cd build
создание файлов для сборки
cmake ..
сборка библиотеки и проекта
make
запуск
./main
```
